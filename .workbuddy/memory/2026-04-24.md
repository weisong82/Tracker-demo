# 2026-04-24

## 微博模拟网站 + 统计SDK项目

- 完成了微博风格前端页面开发，包含信息流、帖子详情、统计看板三个页面
- 核心实现了高性能用户行为统计SDK（WeiboTracker），包含：
  - EventBuffer 批量事件缓冲队列
  - OfflineStore 离线缓存（localStorage兜底）
  - ExposureObserver 曝光检测（IntersectionObserver）
  - ReadTimer 阅读停留计时（支持暂停/恢复，配合页面可见性）
  - ScrollDepthTracker 滚动深度追踪（RAF节流）
  - requestIdleCallback 空闲调度上报
  - sendBeacon 可靠上报（beforeunload场景）
- 技术栈：React 18 + React Router 6 + Vite 5
- 项目运行在 http://localhost:3000
